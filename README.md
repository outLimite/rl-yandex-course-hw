# Reinforcement Learning Yandex Course Homework

Репозиторий с домашними заданиями по курсу **"Обучение с подкреплением"** от Яндекс.

## О курсе

Курс состоит из **4 тренировок** по машинному обучению с фокусом на reinforcement learning (RL).

## Структура репозитория

### 📁 Homework 1: Attention and FMNIST classifiction 
- **Тема:** Реализация механизма внимания и классификация изображений из набора данных FashionMNIST с использованием свёрточных нейронных сетей
- **Основные задачи:**
  - Реализовать аддитивный (additive) и мультипликативный (multiplicative) варианты механизма внимания с использованием
  - Реализовать модель CNN для классификации изображений одежды из датасета FashionMNIST и добиться точности (accuracy) на тестовой выборке не менее 88.5%

### 📁 Homework 2: Crossentropy Method
- **Тема:** Решение RL-задач методом кросс-энтропии
- **Основные задачи:**
  - Реализация табличного метода кросс-энтропии для среды "Taxi-v3"
  - Реализация нейросетевого метода кросс-энтропии для среды "LunarLander-v2"

### 📁 Homework 3: Q-learning with SoftMax Policy
- **Тема:** Реализация и применение Q-learning с SoftMax политикой в средах OpenAI Gym
- **Основные задачи:**
  - Реализация функции SoftMax с температурным параметром
  - Создание Q-learning агента с SoftMax политикой исследования
  - Применение агента к среде Taxi-v3 для проверки работоспособности
  - Анализ влияния температуры на исследование и эксплуатацию

### 📁 Homework 4: Policy Gradient 
- **Тема:** Реализация и обучение агента с помощью алгоритма Policy Gradient (REINFORCE) для решения задачи CartPole-v1
- Построение нейронной сети для предсказания вероятностей действий (политики агента)
- Реализация функции предсказания вероятностей действий на основе состояний среды
- Реализация функции вычисления кумулятивных наград с учетом дисконтирования
- Реализация функции потерь для обучения модели с учетом энтропийной регуляризации
- Обучение агента методом REINFORCE и визуализация результатов

## 🎯 Итоги

Все 4 домашних задания курса были успешно завершены с максимальной оценкой. В процессе обучения были освоены ключевые концепции и методы обучения с подкреплением.
